Developers

VeriTrust API.

Use VeriTrust from your backend, Python scripts, Jupyter notebooks, and automation workflows. Create keys in the dashboard and keep them private.

Authentication

Send API keys with Authorization: Bearer vtg_live_YOUR_API_KEY. Raw keys are shown once when created.

curl "https://YOUR_DOMAIN/api/v1/usage" \
  -H "Authorization: Bearer vtg_live_YOUR_API_KEY"

Phishing API

POST /api/v1/phishing accepts JSON with text and optional model. Use fast, mailguard, robust, or cortex.

curl -X POST "https://YOUR_DOMAIN/api/v1/phishing" \
  -H "Authorization: Bearer vtg_live_YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"text":"Your account will be blocked. Verify your password now.","model":"fast"}'

Deepfake API

POST /api/v1/deepfake accepts multipart/form-data with an image file, optional model, and optional crop=true. Cropping runs inside the VeriTrust API and falls back to the full image if no face crop is available.

curl -X POST "https://YOUR_DOMAIN/api/v1/deepfake" \
  -H "Authorization: Bearer vtg_live_YOUR_API_KEY" \
  -F "image=@sample.jpg" \
  -F "model=fast" \
  -F "crop=true"

Usage, Errors, And Limits

MVP keys default to 100 requests per day. Errors include MISSING_API_KEY, INVALID_API_KEY, REVOKED_API_KEY, INSUFFICIENT_SCOPE, RATE_LIMITED, INVALID_INPUT, MODEL_ERROR, and INTERNAL_ERROR.

Python Examples

import requests

API_KEY = "vtg_live_YOUR_API_KEY"
BASE_URL = "https://YOUR_DOMAIN"

payload = {"text": "Your account will be blocked. Verify your password now.", "model": "fast"}
response = requests.post(
    f"{BASE_URL}/api/v1/phishing",
    headers={"Authorization": f"Bearer {API_KEY}"},
    json=payload,
    timeout=60,
)
data = response.json()
print(data["result"]["label"])
print(data["result"]["risk_level"])
print(data["result"]["confidence"])
import requests

API_KEY = "vtg_live_YOUR_API_KEY"
BASE_URL = "https://YOUR_DOMAIN"
IMAGE_PATH = "sample.jpg"

with open(IMAGE_PATH, "rb") as image_file:
    response = requests.post(
        f"{BASE_URL}/api/v1/deepfake",
        headers={"Authorization": f"Bearer {API_KEY}"},
        files={"image": ("sample.jpg", image_file, "image/jpeg")},
        data={"model": "fast", "crop": "true"},
        timeout=120,
    )

data = response.json()
print(data["result"]["label"])
print(data["result"]["risk_level"])
print(data["result"]["confidence"])

Using VeriTrust API In Jupyter Notebook

import os
import requests
from IPython.display import display, Markdown

API_KEY = os.getenv("VERITRUST_API_KEY")
BASE_URL = "https://YOUR_DOMAIN"

text = """
Your bank account will be locked today.
Verify your password immediately using this link.
"""

response = requests.post(
    f"{BASE_URL}/api/v1/phishing",
    headers={"Authorization": f"Bearer {API_KEY}"},
    json={"text": text, "model": "fast"},
    timeout=60,
)

data = response.json()
display(Markdown(f"""
## VeriTrust Result

**Verdict:** {data["result"]["label"]}  
**Risk:** {data["result"]["risk_level"]}  
**Confidence:** {data["result"]["confidence"]:.2%}  

{data["result"]["summary"]}
"""))
import os

        data={"model": "fast", "crop": "true"},

    )

data = response.json()
display(Markdown(f"""
## VeriTrust Deepfake Detection

**Verdict:** {data["result"]["label"]}  
**Risk:** {data["result"]["risk_level"]}  
**Confidence:** {data["result"]["confidence"]:.2%}  

{data["result"]["summary"]}
"""))

Security Best Practices

Never hardcode production API keys in public notebooks or frontend JavaScript. Use environment variables, secret managers, or your own backend.
