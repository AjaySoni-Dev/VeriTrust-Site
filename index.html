Focused review workflows

VeriTrust combines hosted model output with explainable rule indicators where they are implemented, then presents the result as decision support rather than proof.

Image Review

Submit a supported face image to one of two image classifiers and review normalized real and synthetic-media scores.

  • Image model score review
  • Confidence and risk bands
  • Score-based evidence and limitations

Message Review

Review suspicious email, SMS, URL, or message text using a selected phishing model plus deterministic message indicators.

  • Phishing and legitimate score review
  • URL, credential, urgency, and payment signals
  • Extracted URLs, domains, emails, and phones

Link and API Review

Analyze URL strings without fetching their pages, or call the implemented review routes from a trusted backend with a scoped API key.

  • URL classifier plus deterministic URL patterns
  • Deepfake, phishing, link, and usage API routes
  • Server-side provider tokens and hashed API keys

How a check works

The current web flow validates signed-in requests, calls the selected analysis path, normalizes the result, and records completed web scans in the active workspace.

01

Submit

Choose an image, paste message text, or enter an HTTP or HTTPS URL while signed in.

02

Validate

The server checks authentication, plan quota, input type, payload size, and the selected model key.

03

Analyze

Hosted inference returns model output; message and link checks also apply implemented deterministic indicators.

04

Review

The result dialog shows a verdict, confidence, risk, indicators, fallback status, and a manual-review disclaimer.
