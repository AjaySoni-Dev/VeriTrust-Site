Privacy

How VeriTrust handles submitted content.

VeriTrust may process images, messages, emails, URLs, scan metadata, account information, and API usage metadata to provide AI-assisted digital trust analysis.

Information You Submit

Users may submit image files, suspicious message text, emails, URLs, and related scan metadata. Logged-in scan results may be stored so users can review history and export reports.

Avoid submitting secrets, unnecessary personal data, private credentials, or content you do not have permission to process.

How Data Is Used

Submitted content is used for AI-assisted analysis and to return structured results. API usage metadata may be logged for rate limiting, abuse prevention, diagnostics, and account activity.

API Keys

Raw API keys are shown only once. VeriTrust stores hashes, prefixes, masked values, scope metadata, timestamps, and usage limits, not the raw key value.

Access, Export, And Deletion

Where self-service deletion or export is not available, contact the platform owner to request help. AI results are not guaranteed to be perfect and should be reviewed before high-impact decisions.
