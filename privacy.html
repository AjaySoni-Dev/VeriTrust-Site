Privacy

How VeriTrust handles submitted content.

Version 2.0 - effective 10 July 2026. VeriTrust may process images, messages, emails, URLs, scan metadata, account information, and API usage metadata to provide AI-assisted digital trust analysis.

Controller and contact

VeriTrust operates this service. Privacy requests may be sent to privacy@veritrustlab.in. Security reports should follow security.txt.

Information You Submit

Users may submit image files, suspicious message text, emails, URLs, and related scan metadata. Logged-in scan results may be stored so users can review history and export reports.

Avoid submitting secrets, unnecessary personal data, private credentials, or content you do not have permission to process.

How Data Is Used

Submitted content is used for AI-assisted analysis and to return structured results. API usage metadata may be logged for rate limiting, abuse prevention, diagnostics, and account activity.

API Keys

New API keys are shown only once. VeriTrust stores a non-secret public identifier, a versioned server-HMAC, a masked display hint, scope metadata, timestamps, and usage limits - never the raw key or a secret-bearing prefix.

Access, Export, And Deletion

Retention-disabled text scans store a non-reversible hash and minimal metadata, not a text preview. Automated expiry, export, deletion, and session-revocation operations are shown only when the production lifecycle contract reports availability.
