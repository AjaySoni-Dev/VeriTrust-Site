Getting Started

What is VERITRUST?

VERITRUST is an enterprise-grade AI Security Intelligence Platform designed to help organizations and individuals verify digital media integrity. We provide advanced neural networks specifically trained to detect synthetic manipulation and semantic threats.

How VERITRUST works

Our platform uses a multi-layered approach combining spatial, frequency, and biological artifact detection to calculate a deterministic confidence score for uploaded media. For text payloads, we utilize semantic threat classifiers to identify social engineering patterns.

Supported file types

  • Images: JPG, PNG, WEBP, BMP (Up to 15MB)
  • Videos: MP4, MOV, AVI, MKV, WEBM (Up to 100MB / 2 minutes)
  • Text: Raw text, EML files (For phishing analysis)

Deepfake Detection

Execute highly accurate analysis on image and video payloads via the UI dashboard or API.

  • Upload image or video Ensure your media is uncompressed for the most accurate biological artifact detection.
  • Select model Choose between our V1, V2, or V3 engines depending on your latency and accuracy requirements.
  • Run analysis Our edge network processes the payload completely in-memory (ephemeral processing).
  • Understand results You will receive a 0.0 - 1.0 confidence score alongside visual heatmaps highlighting manipulated boundaries.

Detection Models

VERITRUST offers an ensemble of specialized neural networks tailored for different security requirements.

V1 Fast Engine

Sub-500ms latency. Optimized for high-volume video stream screening and edge deployment.

V2 Balanced Engine

Our standard model. Provides an optimal ratio of compute time to accuracy for general images and videos.

V3 Premium Analysis

Deep spectral frequency inspection. Highest accuracy and reliability for enterprise security teams.

Phishing Detection

Identify targeted spear-phishing and social engineering attacks using our semantic threat classifier.

  • Paste email or message Input the raw text or upload `.eml` files directly into the analyzer.
  • Run AI analysis Our NLP models map intent, urgency flags, and suspicious URL structures.
  • Understand threat levels The platform classifies the payload into severity tiers (Low, Medium, Critical) with a detailed breakdown of triggered heuristics.

API Access

Integrate VERITRUST programmatically into your own platforms via our secure REST endpoints.

Overview

Our API is built on GraphQL and REST standards, providing JSON responses. All connections require TLS 1.3.

POST https://api.veritrust.ai/v1/analyze/media

Example Request

curl -X POST https://api.veritrust.ai/v1/analyze/media \
  -H "Authorization: Bearer vt_live_YOUR_API_KEY" \
  -H "Content-Type: multipart/form-data" \
  -F "model=v2" \
  -F "file=@suspect_video.mp4"

Example Response

{
  "id": "req_8f7b2c9a",
  "status": "completed",
  "model_used": "v2_balanced",
  "results": {
    "is_manipulated": true,
    "confidence_score": 0.984,
    "artifacts_detected": [
      "facial_boundary_mismatch",
      "spectral_inconsistency"
    ]
  }
}

Authentication

Authenticate your API requests using a Bearer token. API keys can be generated in your dashboard. Keep your keys secure and never expose them in client-side code.

Rate Limits

To ensure platform stability, API requests are rate-limited based on your subscription tier:

  • Hobby: 30 requests per minute
  • Pro: 300 requests per minute
  • Enterprise: Custom SLA limits

Best Practices

To ensure the highest accuracy from the VERITRUST platform, follow these guidelines:

  • Upload original media when possible: Compression artifacts from social media platforms (like WhatsApp or Twitter) can degrade detection accuracy.
  • Use high-quality content: Files with extreme pixelation or resolutions below 256x256 may trigger false positives.
  • Human-in-the-loop: Always review AI results alongside human judgment and contextual awareness. AI is an assistant, not an absolute arbiter.

Frequently Asked Questions

How accurate is VERITRUST?

Our V3 model currently benchmarks at 99.2% accuracy against leading academic datasets (FaceForensics++, Celeb-DF). However, real-world accuracy varies depending on media compression and generation techniques.

What file types are supported?

We support standard image formats (JPG, PNG, WEBP, BMP) and video formats (MP4, MOV, AVI, MKV, WEBM). Maximum file size is 100MB.

Is my data stored?

No. VERITRUST uses ephemeral processing. Payload data is processed entirely in-memory and is securely wiped immediately after the analysis report is generated. We do not use client data to train our models.

How does phishing detection work?

It utilizes Natural Language Processing (NLP) to detect urgency cues, domain spoofing, semantic anomalies, and known social-engineering attack patterns within text and email headers.
