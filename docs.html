VERITRUST deployment guide.

`VaryTrust-Domain` is now ready for GitHub plus Vercel. Static pages live at the project root, Vercel serverless functions live in `api/*.js`, and the Hugging Face token stays in Vercel environment variables.

Vercel Setup

  1. Push the `VaryTrust-Domain` folder contents to a GitHub repository.
  2. Import the repository in Vercel.
  3. Add `HF_ACCESS_TOKEN` in Project Settings, Environment Variables.
  4. Deploy, then open `/api/health` and confirm `"token_configured": true`.
HF_ACCESS_TOKEN=hf_your_token_here

Deepfake Flow

  1. `deepfake.html` uploads the image in the browser.
  2. The optional crop step calls the Hugging Face Space endpoint in `assets/js/config.js`.
  3. `/api/deepfake` sends the selected crop or original image to Hugging Face Inference.
  4. The result is normalized into Real, Fake, confidence, and risk level.

Phishing Flow

  1. `phishing.html` sends JSON to `/api/phishing`.
  2. MailGuard returns classifier scores for standard threat checks.
  3. Cortex uses chat completion for broader context reasoning.
  4. The response is normalized into Phishing or Legitimate.

API Files

  • api/health.js: confirms the token is configured.
  • api/deepfake.js: accepts multipart image uploads and model key `pixel` or `prism`.
  • api/phishing.js: accepts JSON text and model key `mailguard` or `cortex`.
  • lib/veritrust-api.js: shared Vercel API helpers.
  • api/*.php: retained only for legacy PHP hosting.
