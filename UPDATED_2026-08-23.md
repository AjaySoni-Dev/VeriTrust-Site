# Z Sphere — Complete UI, Navigation & Public Access Update

Updated: 2026-08-23

## Front-end changes
- Renamed landing-page routing is standardized on `index2.html` throughout live HTML and JavaScript.
- `/` rewrites to `index2.html`; legacy `/index.html` permanently redirects to `index2.html` on Vercel.
- Dark theme is the only supported theme. Light-theme toggles and saved theme switching were removed.
- Added `css/polish.css` for compact typography, spacing, controls, cards, event pages, account pages and admin pages.
- Added `js/motion.js` for reveal animation, stagger, header state, subtle hero interaction, async-content animation and reduced-motion support.
- Added Gallery to the canonical navigation so public memory content is directly discoverable.
- Corrected explicit light backgrounds in admin/mobile surfaces while preserving a light QR backing where contrast is technically required.
- Reduced oversized page titles, section headings, cards, images, form controls, admin tables and hero regions.
- Normalized the dark palette, muted text contrast, borders, focus rings, hover effects and shadows.

## Guest browsing vs registration
Guests can browse published/public content without signing in:
- Published/completed/cancelled event details
- Public announcements
- Published gallery albums and memory images
- Active team members
- Public media assets

Authentication is required for registration/community links:
- Anonymous database access does not receive `registration_form_url` or `whatsapp_group_url`.
- Event pages show `Sign In to Register` to guests only when registration is open.
- After sign-in, the user is returned to the same event page and can receive the protected registration link.
