01

Prerequisites

Before you start

Use Windows PowerShell 5.1 or PowerShell 7 on your own computer. You need a VeriTrust API key created inside the organization that will own the scans.

K

Organization API key

Create a fresh key from API Access. New keys include gateway scan, read, and cancel permissions.

Open API Access →
P

PowerShell

Open a normal PowerShell window. Administrator mode is not required.

S

Safe test content

Use content and files you are authorized to process. Start with a controlled test case.

Keep the key private.Never place the real key inside a command, screenshot, chat, repository, or shared document. The secure prompt below keeps it out of command history.
02

Run once per session

Secure setup and authentication

Copy this complete block into PowerShell. When prompted, paste the API key and press Enter. The key appears only as asterisks.

PowerShellSecure session setup
[Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12

$BaseUrl = "https://www.veritrustlab.in"
$SecureApiKey = Read-Host "Paste your VeriTrust API key" -AsSecureString
$ApiKey = (New-Object System.Net.NetworkCredential("", $SecureApiKey)).Password

if ($ApiKey -notmatch '^vtg_(live|test)_[A-Za-z0-9_-]{20,}$') {
    throw "The entered value is not a valid VeriTrust API key."
}

$AuthHeaders = @{ Authorization = "Bearer $ApiKey" }
$Authentication = Invoke-RestMethod `
    -Method Get `
    -Uri "$BaseUrl/api/v1/gateway/scans?limit=1" `
    -Headers $AuthHeaders `
    -ErrorAction Stop

if ($Authentication.ok -ne $true) {
    throw "VeriTrust authentication failed."
}

Write-Host "Authenticated with VeriTrust." -ForegroundColor Green
Expected outputAuthenticated with VeriTrust. Keep this PowerShell window open for the examples below.
03

Focused detection

Phishing message only

Use this when you want the gateway to assess email, SMS, or chat text. URLs found inside the message are extracted and assessed automatically.

PowerShellSubmit, wait, and show phishing result
$PhishingText = @"
URGENT: Your Microsoft 365 account will be suspended today.
Confirm your password immediately using the verification link.
"@

$IdempotencyKey = [Guid]::NewGuid().ToString()
$Headers = @{
    Authorization     = "Bearer $ApiKey"
    "Idempotency-Key" = $IdempotencyKey
}

$Payload = @{
    source = @{
        kind              = "powershell"
        external_event_id = "phishing-$([Guid]::NewGuid())"
    }
    content = @{
        text  = $PhishingText
        urls  = @()
        media = @()
    }
    processing_mode = "synchronous"
    metadata = @{
        client             = "windows-powershell"
        context_categories = @("email")
    }
}

$Submission = Invoke-RestMethod `
    -Method Post `
    -Uri "$BaseUrl/api/v1/gateway/scans" `
    -Headers $Headers `
    -ContentType "application/json" `
    -Body ($Payload | ConvertTo-Json -Depth 20 -Compress) `
    -ErrorAction Stop

$ScanId = $Submission.scan_id
do {
    $Result = Invoke-RestMethod `
        -Method Get `
        -Uri "$BaseUrl/api/v1/gateway/scans/$ScanId" `
        -Headers $AuthHeaders `
        -ErrorAction Stop

    Write-Host "Status: $($Result.status)"
    if (@("completed", "failed", "cancelled") -notcontains $Result.status) {
        Start-Sleep -Seconds 3
    }
} while (@("completed", "failed", "cancelled") -notcontains $Result.status)

$Result.decision | Format-List
$Result.evidence |
    Select-Object model, status, score, verdict, confidence, reason_codes |
    Format-List

Recommended gateway flow

Combined phishing and link scan

Use this for a suspicious email containing one or more links. The gateway runs applicable models separately, correlates their evidence, then returns one policy-backed recommendation.

PowerShellSubmit and correlate message plus URL
$MessageText = @"
Your account has been locked because of suspicious activity.
Verify your identity immediately using the supplied link.
"@

$UrlsToCheck = @("https://example.com/security-verification")
$IdempotencyKey = [Guid]::NewGuid().ToString()
$Headers = @{
    Authorization     = "Bearer $ApiKey"
    "Idempotency-Key" = $IdempotencyKey
}

$Payload = @{
    source = @{
        kind              = "powershell"
        external_event_id = "combined-$([Guid]::NewGuid())"
    }
    content = @{
        text  = $MessageText
        urls  = $UrlsToCheck
        media = @()
    }
    processing_mode = "hybrid"
    metadata = @{
        client             = "windows-powershell"
        context_categories = @("email", "credential")
    }
}

$Submission = Invoke-RestMethod `
    -Method Post `
    -Uri "$BaseUrl/api/v1/gateway/scans" `
    -Headers $Headers `
    -ContentType "application/json" `
    -Body ($Payload | ConvertTo-Json -Depth 20 -Compress) `
    -ErrorAction Stop

$ScanId = $Submission.scan_id
do {
    $Result = Invoke-RestMethod `
        -Method Get `
        -Uri "$BaseUrl/api/v1/gateway/scans/$ScanId" `
        -Headers $AuthHeaders `
        -ErrorAction Stop

    $Verdict = if ($Result.decision) { $Result.decision.verdict } else { "pending" }
    Write-Host "Status: $($Result.status) | Verdict: $Verdict"

    if (@("completed", "failed", "cancelled") -notcontains $Result.status) {
        Start-Sleep -Seconds 3
    }
} while (@("completed", "failed", "cancelled") -notcontains $Result.status)

Write-Host "Recommendation: $($Result.decision.recommendation)"
Write-Host "Risk: $([Math]::Round(([double]$Result.decision.risk * 100), 2))%"
$Result.decision | Format-List
$Result.evidence |
    Select-Object model, model_key, score, verdict, confidence, reason_codes |
    Format-List
06

Private media pipeline

Image deepfake detection

This flow registers a private upload, sends the image through its short-lived signed URL, verifies the stored object, submits an image-only scan, and waits for the media worker.

Image-only matters.The payload intentionally sets text = $null. Adding instructions such as “analyze this image” creates a separate phishing-text artifact and can influence the combined risk.
PowerShellUpload and analyze one image
$ImagePath = "C:\SecurityTests\suspected-image.jpg"

if (-not (Test-Path -LiteralPath $ImagePath)) {
    throw "Image not found: $ImagePath"
}

$ImageFile = Get-Item -LiteralPath $ImagePath
$MimeTypes = @{
    ".jpg"  = "image/jpeg"
    ".jpeg" = "image/jpeg"
    ".png"  = "image/png"
    ".webp" = "image/webp"
    ".bmp"  = "image/bmp"
}

$ImageMimeType = $MimeTypes[$ImageFile.Extension.ToLowerInvariant()]
if ([string]::IsNullOrWhiteSpace($ImageMimeType)) {
    throw "Use a JPG, JPEG, PNG, WEBP, or BMP image."
}
if ($ImageFile.Length -gt 10MB) {
    throw "The image exceeds the 10 MB gateway image limit."
}

$RegisterPayload = @{
    kind       = "image"
    mime_type  = $ImageMimeType
    size_bytes = $ImageFile.Length
}

$RegisteredUpload = Invoke-RestMethod `
    -Method Post `
    -Uri "$BaseUrl/api/v1/gateway/uploads" `
    -Headers $AuthHeaders `
    -ContentType "application/json" `
    -Body ($RegisterPayload | ConvertTo-Json -Compress) `
    -ErrorAction Stop

$SignedUploadUrl = [string]$RegisteredUpload.signed_upload.url
if ($SignedUploadUrl -notmatch '^https?://') {
    $ClientConfig = Invoke-RestMethod `
        -Method Get `
        -Uri "$BaseUrl/api/client-config" `
        -ErrorAction Stop

    $SupabaseUrl = ([string]$ClientConfig.config.supabase.url).TrimEnd("/")
    $SignedUploadUrl = "$SupabaseUrl/storage/v1$SignedUploadUrl"
}

$StorageResponse = Invoke-WebRequest `
    -Method Put `
    -Uri $SignedUploadUrl `
    -InFile $ImageFile.FullName `
    -ContentType $ImageMimeType `
    -Headers @{ "x-upsert" = "false" } `
    -UseBasicParsing `
    -ErrorAction Stop

if ($StorageResponse.StatusCode -lt 200 -or $StorageResponse.StatusCode -ge 300) {
    throw "Private image upload failed."
}

$CompletedUpload = Invoke-RestMethod `
    -Method Post `
    -Uri "$BaseUrl/api/v1/gateway/uploads/$($RegisteredUpload.upload_id)/complete" `
    -Headers $AuthHeaders `
    -ErrorAction Stop

if ($CompletedUpload.status -ne "uploaded") {
    throw "The gateway did not confirm the private upload."
}

Complete gateway workflow

Unified text, link, and image scan

Use this when one security event contains a suspicious message, one or more URLs, and an image. The gateway registers the image privately, evaluates every applicable artifact, and correlates phishing, link, and deepfake evidence into one policy decision.

One event, one decision.The text, URLs, and image are submitted in the same request. Do not submit the image separately if you need a genuinely unified result across all three signal types.
PowerShellUpload, submit, and correlate all signals
$MessageText = @"
Your Microsoft 365 account has been locked.
Verify your password immediately using the supplied link and QR image.
"@

$UrlsToCheck = @("https://example.com/security-verification")
$ImagePath = "C:\SecurityTests\suspected-qr-image.jpg"

if (-not (Test-Path -LiteralPath $ImagePath -PathType Leaf)) {
    throw "Image not found: $ImagePath"
}

$ImageFile = Get-Item -LiteralPath $ImagePath
$MimeTypes = @{
    ".jpg"  = "image/jpeg"
    ".jpeg" = "image/jpeg"
    ".png"  = "image/png"
    ".webp" = "image/webp"
    ".bmp"  = "image/bmp"
}

$ImageMimeType = $MimeTypes[$ImageFile.Extension.ToLowerInvariant()]
if ([string]::IsNullOrWhiteSpace($ImageMimeType)) {
    throw "Use a JPG, JPEG, PNG, WEBP, or BMP image."
}
if ($ImageFile.Length -lt 1 -or $ImageFile.Length -gt 10MB) {
    throw "The image must contain data and must not exceed 10 MB."
}

$RegisterPayload = @{
    kind       = "image"
    mime_type  = $ImageMimeType
    size_bytes = $ImageFile.Length
}

$RegisteredUpload = Invoke-RestMethod `
    -Method Post `
    -Uri "$BaseUrl/api/v1/gateway/uploads" `
    -Headers $AuthHeaders `
    -ContentType "application/json" `
    -Body ($RegisterPayload | ConvertTo-Json -Compress) `
    -ErrorAction Stop

if ([string]::IsNullOrWhiteSpace([string]$RegisteredUpload.upload_id)) {
    throw "The gateway did not return an upload identifier."
}

$SignedUploadUrl = [string]$RegisteredUpload.signed_upload.url
if ($SignedUploadUrl -notmatch '^https?://') {
    $ClientConfig = Invoke-RestMethod `
        -Method Get `
        -Uri "$BaseUrl/api/client-config" `
        -ErrorAction Stop

    $SupabaseUrl = ([string]$ClientConfig.config.supabase.url).TrimEnd("/")
    if ([string]::IsNullOrWhiteSpace($SupabaseUrl)) {
        throw "The signed upload URL could not be resolved."
    }
    $SignedUploadUrl = "$SupabaseUrl/storage/v1$SignedUploadUrl"
}

$StorageResponse = Invoke-WebRequest `
    -Method Put `
    -Uri $SignedUploadUrl `
    -InFile $ImageFile.FullName `
    -ContentType $ImageMimeType `
    -Headers @{ "x-upsert" = "false" } `
    -UseBasicParsing `
    -ErrorAction Stop

if ($StorageResponse.StatusCode -lt 200 -or $StorageResponse.StatusCode -ge 300) {
    throw "Private image upload failed with HTTP $($StorageResponse.StatusCode)."
}

$CompletedUpload = Invoke-RestMethod `
    -Method Post `
    -Uri "$BaseUrl/api/v1/gateway/uploads/$($RegisteredUpload.upload_id)/complete" `
    -Headers $AuthHeaders `
    -ErrorAction Stop

if ($CompletedUpload.status -ne "uploaded") {
    throw "The gateway did not confirm the private image upload."
}

$IdempotencyKey = [Guid]::NewGuid().ToString()
$Headers = @{
    Authorization     = "Bearer $ApiKey"
    "Idempotency-Key" = $IdempotencyKey
}

$Payload = @{
    source = @{
        kind              = "powershell"
        external_event_id = "unified-$([Guid]::NewGuid())"
    }
    content = @{
        text  = $MessageText
        urls  = $UrlsToCheck
        media = @(
            @{
                upload_id = $RegisteredUpload.upload_id
                kind      = "image"
            }
        )
    }
    processing_mode = "hybrid"
    metadata = @{
        client             = "windows-powershell"
        context_categories = @("email", "credential", "qr-image")
    }
}

$Submission = Invoke-RestMethod `
    -Method Post `
    -Uri "$BaseUrl/api/v1/gateway/scans" `
    -Headers $Headers `
    -ContentType "application/json" `
    -Body ($Payload | ConvertTo-Json -Depth 20 -Compress) `
    -ErrorAction Stop

$ScanId = [string]$Submission.scan_id
if ([string]::IsNullOrWhiteSpace($ScanId)) {
    throw "The gateway accepted no scan identifier."
}

$Deadline = [DateTimeOffset]::UtcNow.AddMinutes(5)
do {
    $Result = Invoke-RestMethod `
        -Method Get `
        -Uri "$BaseUrl/api/v1/gateway/scans/$ScanId" `
        -Headers $AuthHeaders `
        -ErrorAction Stop

    $CurrentVerdict = if ($null -ne $Result.decision) {
        [string]$Result.decision.verdict
    } else {
        "pending"
    }
    Write-Host "Status: $($Result.status) | Verdict: $CurrentVerdict"

    if (@("completed", "failed", "cancelled") -contains $Result.status) {
        break
    }
    if ([DateTimeOffset]::UtcNow -ge $Deadline) {
        throw "The scan is still processing after five minutes. Scan ID: $ScanId"
    }
    Start-Sleep -Seconds 4
} while ($true)

if ($Result.status -ne "completed") {
    throw "The unified scan ended with status '$($Result.status)'. Scan ID: $ScanId"
}
if ($null -eq $Result.decision) {
    throw "The unified scan completed without a policy decision. Scan ID: $ScanId"
}

Write-Host ""
Write-Host "Unified decision" -ForegroundColor Cyan
Write-Host "Verdict: $($Result.decision.verdict)"
Write-Host "Recommendation: $($Result.decision.recommendation)"
Write-Host "Risk: $([Math]::Round(([double]$Result.decision.risk * 100), 2))%"

$Result.artifacts |
    Select-Object type, status, mime_type, size_bytes |
    Format-Table -AutoSize

$Result.evidence |
    Select-Object model, model_key, status, score, verdict, confidence, reason_codes |
    Format-List

The first response can contain a preliminary decision while the private image worker runs. This example waits for the completed result before displaying the final correlated outcome.

Interpretation

Understand the response

Decision

One policy outcome

risk, verdict, and recommendation summarize the correlated result across applicable artifacts.

Evidence

Per-model findings

Each entry identifies its model, score, verdict, confidence, reason codes, and recorded model version.

Status

Processing lifecycle

completed is final. Image scans can move through accepted, processing, and partially completed states first.

Review

Human checkpoint

Manual review means the case should be examined with source context before a consequential action.

Low0–44%
Medium45–74%
High75–89%
Critical90–100%
Advisory enforcementA recommendation such as quarantine does not automatically block a message or URL while organization enforcement is disabled. Your downstream integration must apply the final action.
10

Recovery

Common errors

401 This endpoint requires a valid Bearer token

The key is missing, invalid, expired, or revoked. Create a new organization API key and rerun the secure setup block. Do not type the key inside the Read-Host prompt label.

403 API key has no gateway permissions

Create a new key after gateway access is enabled. It must include gateway:scan, gateway:read, and gateway:cancel.

409 Idempotency conflict

Reuse an idempotency key only when retrying the exact same request body. Generate a new GUID when the content changes.

415 Unsupported image type

Use JPG, JPEG, PNG, WEBP, or BMP. The declared MIME type must match the stored file.

429 Gateway quota exceeded

The API key or organization has reached its current plan limit. Review usage and plan information in the dashboard.

Operational safety

Finish securely

Never print the key

Avoid commands such as Write-Host $ApiKey and never include the value in screenshots.

Use one key per integration

Separate keys make rotation, revocation, scopes, and usage attribution manageable.

Preserve request IDs

Store the scan, request, trace, and external event identifiers with your incident record.

Clear the session

Remove the decrypted key from variables when the session is finished.

PowerShellClear credentials from the current session
$ApiKey = $null
$SecureApiKey = $null
$AuthHeaders = $null
[System.GC]::Collect()
Write-Host "VeriTrust session cleared." -ForegroundColor Green
