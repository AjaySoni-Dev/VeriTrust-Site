1. Connect once per session

Open Windows PowerShell 5.1 or PowerShell 7. Create an API key, then run this line and paste it into the secure prompt. The line loads and runs the official script linked above.

PowerShell 
. ([scriptblock]::Create((Invoke-WebRequest https://www.veritrustlab.in/vt.ps1 -UseBasicParsing -ErrorAction Stop).Content)); vt login

2. Choose a check

Investigate an email file

Use an original .eml file. Quote paths containing spaces.

PowerShell 
vt email "email.eml"

Check email text

Use single quotes to keep dollar signs literal. Double any apostrophe inside the message. The subject is optional.

PowerShell 
vt text 'Please verify your account' -Subject 'Account notice'

Check a link

The URL is submitted to the Gateway link analysis service.

PowerShell 
vt link "https://example.com"

Check an image

The image is uploaded to private storage and submitted for Gateway analysis. Supports JPG, PNG, WebP, and BMP up to 10 MB.

PowerShell 
vt image "face.png"

Follow an existing scan

Use the report ID returned by the server. Pending and unavailable checks remain explicit.

PowerShell 
vt status "YOUR-SCAN-ID"

Disconnect

Removes the credential from the helper session. Close PowerShell when finished.

PowerShell 
vt logout

3. Results and troubleshooting

Results show a concise summary. To retain the full evidence, assign a command to $result, then inspect $result.TechnicalReport.

Progress shows request activity or status reported by the server. No percentage is estimated. If a scan is still pending after the wait period, use its report ID with vt status or open Gateway history.

A transient connection failure retries once with the same request ID. If it still fails, the request may already exist: check Gateway history before submitting again. Authentication and input errors are reported without retrying. Email investigations returned as processing can also be followed in Gateway history.

If vt is not recognized, run the connection line again in this window. Use the Copy command buttons to avoid copying Markdown links or console prompts. Existing Invoke-VeriTrustEmailInvestigation commands remain supported.
